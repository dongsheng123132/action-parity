# 影核网页验收 Profile（试行）

本 Profile 补充 `PROPOSAL-WEB-PROFILE.zh-CN.md`，不修改 ActionParity 核心同源定义。

## 两类结论

**网页 AI 办事体检**可在黑盒条件下验证：任务是否可发现、语义 HTML/ARIA 与原生控件是否可用、Agent 或 Computer Use 是否在约定账号和环境中完成任务、错误/重试/权限状态是否可观察。

**影核同源验证**还必须有可审查的 Manifest、Binding、Action Core 和执行证据，证明不同入口对同一业务动作使用同一 Action ID、核心路径、策略和状态。黑盒跑通不得称为同源验证。

## 网页任务最低证据

1. 明确任务、版本、环境和授权范围。
2. 页面入口、字段 label、稳定 action ID、键盘路径及持续状态文字。
3. Agent/API 与网页使用同一资源 ID 读写，记录版本、幂等重放和陈旧冲突结果。
4. Computer Use 必须标明语义/DOM 模式或纯视觉模式；两者结论不得互相替代。
5. 写操作只在测试账号与约定范围执行；证据脱敏且不含认证秘密。

## 声明边界

报告只能声明指定版本、环境和任务的结果。代码、依赖或环境变化后证据应标记待复测。自测、服务方测试和独立验证必须分别标注。
