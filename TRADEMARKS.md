# ActionParity Trademark Policy

**Status:** interim project policy for the working draft

This policy is not a statement that any mark is registered, not a trademark
clearance opinion, and not legal advice. The project must identify a stable
owner and complete professional clearance before filing or licensing marks.

The Apache License 2.0 permits broad use of the specification and software, but
does not grant a general right to use a licensor's trademarks. This policy
explains the broader uses the project intends to allow while protecting the
meaning of official conformance claims.

## Uses that are welcome

No separate permission is needed to:

- truthfully state that software implements or was self-tested against an exact
  ActionParity draft, such as `ActionParity 0.1.0 AP-2`;
- discuss, compare, criticize, teach, or link to ActionParity;
- use the name in an implementation report or compatibility matrix;
- redistribute an unmodified official specification or validator with its
  notices; or
- describe a fork as “based on ActionParity” when the fork is clearly
  distinguished from the official project.

The name should be used as an adjective or compatibility reference, not as a
claim that the implementation is the official project.

## Uses that need written permission

Written permission is required to:

- use `ActionParity` in a company, product, service, domain, package scope, or
  event name in a way that may look official;
- use an official logo as the primary branding of another product;
- run a commercial certification program under the ActionParity name; or
- issue official-looking badges, seals, certificates, or registry entries.

## Uses that are not currently available

There is no official certification program yet. Do not use:

- `ActionParity Certified`;
- `Official ActionParity`;
- an official-looking compliance badge; or
- language implying endorsement, partnership, or independent verification.

Self-test statements remain welcome when they identify the exact draft,
application version, operating system, report, and evidence.

## Forks and distributions

Forking and commercial distribution remain permitted by the applicable open
source license. A materially modified fork should use a distinct project name
and must not present modified results as reports issued by the official
ActionParity project.

## Future certification

Before a certification mark or badge is offered, the project will publish:

- objective and reproducible pass/fail rules;
- permitted badge use and expiration;
- verifier independence requirements;
- revocation and appeal procedures; and
- vendor-neutral access across operating systems and implementations.

The trademark protects trust in the conformance claim. It must never become a
private veto over implementing the open specification.
